# Habit Flow AI

**Habit Flow AI** ek modern, feature-rich aur interactive single-file Streamlit web application hai jo users ko unke daily habits, goals, aur moods ko track karne mein madad karta hai. Yeh personalized AI-powered motivation, reminders, aur gorgeous 3D/glassmorphic UI ke sath aata hai.

---

## ✨ Features

- **🔐 Secure Authentication & Onboarding:**
  - Built-in login aur signup system (secure password hashing ke sath).
  - Interactive first-time **Onboarding Tour (Gaming-style guide)** jo naye users ko step-by-step app use karna sikhata hai.
- **🎯 Advanced Goal Management:**
  - Multiple goal types: Short-term pushes, Long-term dreams, aur Daily habits.
  - Interactive checkboxes aur progress tracking bar.
- **⏰ Live Reminders & Timers:**
  - Goals ke liye live countdown timers aur snooze (`+5 min`) ka feature.
  - Custom audio alerts aur toast notifications.
- **🧠 Mood Check-in & AI Tips Library:**
  - 9+ different moods (Happy, Focused, Stressed, Tired, etc.) select karne ka option.
  - 100+ dynamic, personalized motivational tips jo user ke name aur selected goal ke sath map hoti hain.
- **🎨 Modern 3D & Responsive Design:**
  - Glassmorphic cards, smooth hover animations, aur gradient buttons.
  - Dynamic **Dark / Light Mode Toggle** jisme light mode ke liye high-contrast input text boxes diye gaye hain.
  - Goal complete hone par celebratory **Confetti & Particle Effects**.
- **📈 Session Storage & History:**
  - Completed goals aur received AI tips ka session-based history log.
  - Sidebar profile settings jisse user apna Name, App Name, Username, aur Password change kar sakta hai, ya apna data reset/delete kar sakta hai.

---

## 🛠️ Tech Stack

- **Python** (Core Logic)
- **Streamlit** (Web Framework & UI Components)
- **HTML5 & CSS3** (Custom 3D / Glassmorphism Styling & Animations)
